# Abdullah Sadeed — Cybersecurity Portfolio

Personal portfolio website for Abdullah Sadeed, focused on cybersecurity learning, CTFs, practical labs, and technical projects.

## Files

- `index.html` — portfolio website
- `photo.png` — profile image used by the portfolio
- `resume.pdf` — downloadable resume

## Run locally

Open `index.html` directly in a browser, or use a local web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
